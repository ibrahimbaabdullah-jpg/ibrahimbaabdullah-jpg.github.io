# Ibrahim Baabdullah — Academic Portfolio

Personal academic website for Ibrahim Baabdullah, focused on nursing and health informatics.

## Website
https://ibrahimbaabdullah-jpg.github.io/

## Structure
- `index.html`: academic biography, research, outputs, education and experience
- `projects.html`: research and educational project descriptions and public links
- `assets/style.css`: responsive, accessible styling
- `assets/Ibrahim-Baabdullah-Public-CV.pdf`: public CV with approved contact details
- `assets/favicon.svg`: site monogram

Static HTML and CSS. No build dependencies, analytics, third-party fonts, tracking or backend.

## Local preview
Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

## Publishing
GitHub Pages serves `main` from the repository root. Changes to the published branch update the website.

## Content maintenance
Keep the CV and web sections consistent. Research and educational projects must retain their prototype limitations. Link only publicly available repositories and demos. Never upload private contact information, credentials, patient data or unpublished source data.
