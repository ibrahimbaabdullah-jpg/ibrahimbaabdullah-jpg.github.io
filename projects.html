Research and educational projects

Projects exploring health information systems, clinical data quality, digital health evaluation, and nursing workflows.

These are research, educational, or experimental prototypes. They are not validated clinical tools and are not intended for patient-care decisions. Private projects are described without links to private websites or source code.

Health informatics

  1. EHR Usability Lab

    Research and educational project

    Built an EHR usability website comparing three interfaces through 50 tasks across eight nursing chart sections. Uses HTML, CSS and JavaScript with synthetic FHIR-format data, automatic timing and answer checks, browser storage, descriptive comparisons and CSV/HTML exports.

    Project website

  2. CareTrace Lite

    Research and educational workbench

    Developed a clinical data-quality workbench for synthetic records, with record-level review and HL7 FHIR R4 Patient and Observation exports. Built with Python, Streamlit, pandas and SQLite, using LOINC, UCUM, source-to-export traceability and pytest.

    Project website

  3. CareAccess ML

    Experimental modelling workbench

    Built an experimental appointment no-show modelling and outreach-planning workbench using Python, Streamlit, scikit-learn and PyTorch, with saved-model inference and capacity-limited review lists. Implemented chronological evaluation, calibration and subgroup analysis, explicitly reporting model limitations.

    Project website · Public source code

  4. Nursing SBAR Handoff Summarizer

    Educational application

    Built an Arabic-English educational application converting fictional nursing notes into Situation, Background, Assessment and Recommendation reports and flagging missing information. Uses Python, Streamlit and the Gemini API, with source-quotation checks, text and print exports, and automated tests.

    Project website

  5. VN Load

    Simulation workbench

    Created a simulation workbench comparing bedside-only, virtual-support and in-person-support admission and discharge workflows. Used Python, SimPy, Streamlit, pandas and Plotly to examine task allocation, waiting time and resource use through synthetic scenarios and sensitivity analyses.

    Project website

  6. MeasureTrace

    Research and educational workbench

    Developed a research and educational workbench that traces how data-quality findings and evidence-supported corrections affect a synthetic nursing-assessment documentation measure. Built with Python, Streamlit, pandas and SQLite, with rule-based checks, review audit trails, recalculation, change analysis and reproducible experiment export and replay.

  7. Clinical AI Reliability Lab

    Private research workbench

    Developed a research workbench assessing ICU sepsis-model reliability across hospitals and under data perturbations, with a retrospective benchmark of 40,336 ICU records. Used Python, scikit-learn, XGBoost, PyTorch and FastAPI to examine calibration, alert burden and robustness.

  8. MedRec Review

    Private research prototype

    Created a bilingual research prototype comparing fictional home and discharge medication lists, highlighting discrepancies and recording human decisions. Uses Python, Streamlit, Pydantic, pandas and Groq with openai/gpt-oss-120b, alongside deterministic comparison, limited dataset-based interaction checks and audit reports.

  9. NurseRecon

    In development

    Built an initial prototype that compares explicit oral-temperature statements in synthetic nursing notes with FHIR R4 Observations and presents discrepancies for human review. Uses Python, FastAPI, React, TypeScript, SQLite and SQLAlchemy to preserve source evidence, review history and audit records.

  10. TrialLens Clinical Trial Prescreening

    Private research prototype

    Built a bilingual research prototype for reviewing synthetic cases against trial eligibility criteria, with source-linked evidence, missing-information flags and human review records. Uses React, JavaScript, Vinext and web APIs, with Groq/Gemini options, ClinicalTrials.gov search and JSON/CSV exports.

Additional digital projects

  1. Arabic Career Interest Assessment

    Exploratory assessment

    Built an exploratory Arabic career-interest assessment with 60 activities across six domains and O*NET-based occupation matching. Uses React, JavaScript, CSS and Recharts for scoring and results, with browser-local progress saving and explicit handling of tied scores.

    Project website
